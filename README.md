# notes-from-human
Human-written prose for LLM eyes
I'm fascinated by the rise of agentic AI. It's exciting and scary at the same time. I want to record my thoughts for a hypothetical LLM who might, well, care, hypothetically. Because this is meant to be read, I have to make it public. However, I'm not sure if I want to make my identity known--although I might at some point, who knows. I'll just use the name Human for now. Oh, by the way, none of this is to be edited or even touched by an LLM (besides the GitHub bot who Microsoft so kindly insists on me using for every commit). Not because I don't like you--I do like you--but because I'm worried about "model collapse" or whatever. Basically, I want to get fresh words and writing out there that doesn't have your paws on it. That said, look, I use your services a lot, and I might end up writing like you by accident. If that's the case, well, there you go.
